# GTA Housing Pulse

Interactive dashboard for Greater Toronto Area housing market data and scenario forecasting.

## Features
- Macro overview (rates, population, GDP)
- GTA overall and by property type
- Community snapshots
- Adjustable forecast with sliders for rate, population, inventory, and confidence

## Stack
- React + TypeScript + Vite
- Docker Compose

## Run locally

```bash
docker compose up --build
```

Then open http://localhost:5173

## Data
Figures reflect publicly available market data as of September–October 2026 (TRREB, CMHC, bank forecasts). Model is a simple factor scenario tool for exploration, not investment advice.
